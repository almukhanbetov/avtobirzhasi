# Skill: User Dashboard — avtobirzhasi.kz

## Goal
Create a clean user area that feels consistent with the public automotive site, not like a generic admin template.

## Navigation
Desktop:
- Overview
- Мои объявления
- Заявки на покупку
- Matches
- Депозиты
- Избранное
- Уведомления
- Профиль

Use either:
- slim left sidebar;
or
- top/sub navigation.

Do not use an oversized enterprise sidebar.

## Dashboard overview
Show only useful information.

Summary:
- Active seller listings
- Buyer requests
- Active matches
- Favorites

Then prioritize active tasks:
- Deposit required
- Match deadline
- Listing awaiting moderation
- New notification

## Listings table/cards
Desktop may use structured rows with thumbnail.
Mobile should use cards.

Display:
- car;
- type: seller / buyer;
- current price;
- status;
- updated date;
- key action.

## Match cards
Important active matches must stand out.

Show:
- car image;
- current/final price;
- deposit status;
- deadline;
- action.

## Empty states
Examples:
No seller listings:
"У вас пока нет объявлений о продаже."

CTA:
"Продать автомобиль"

No buyer requests:
"Создайте заявку, и автобиржа будет искать подходящий автомобиль автоматически."

CTA:
"Создать заявку"

## Notifications
Use readable categories:
- Match найден
- Нужно внести депозит
- Депозит получен
- Контакты открыты
- Срок Match истёк

## Style
Use same:
- typography;
- radius;
- spacing;
- primary brand color;
- button system
as public site.

Avoid switching to a totally different visual system inside dashboard.
